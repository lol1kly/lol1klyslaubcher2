# BlockLaunch — лаунчер Minecraft (проект)

Это исходный проект Windows-лаунчера с GUI. Включает:
- выбор/установку релизных и снапшот-версий через `minecraft-launcher-lib`;
- отдельный каталог для каждой версии/профиля;
- скачивание Java runtime в каталог лаунчера через Adoptium API (по требуемой major-версии);
- офлайн-профиль (локальный ник; **не** даёт доступ к серверам, требующим Microsoft-аутентификацию);
- поиск модов на Modrinth и скачивание выбранного файла в папку `mods` выбранного профиля;
- сборочный скрипт для создания `.exe` на Windows.

## Важное ограничение
В этом окружении нельзя собрать и проверить Windows `.exe`, поэтому архив содержит проект и `build_windows.bat`, а не готовый `BlockLaunch.exe`. Я не буду выдавать исходники за готовый EXE. Для сборки на Windows нужен Python 3.11+ и интернет на время установки зависимостей/сборки. После сборки запуск самого лаунчера не требует отдельной установки Python; Java и файлы Minecraft скачиваются самим приложением по запросу.

## Запуск из исходников
1. Установите Python 3.11+ для Windows.
2. Запустите `run_windows.bat`.
3. При первом запуске проект установит нужные Python-пакеты.

## Сборка EXE
Запустите `build_windows.bat`. Готовый файл появится в `dist\\BlockLaunch.exe`.

## Примечания
- Minecraft Java Edition и моды принадлежат соответствующим правообладателям/авторам; лаунчер скачивает их из официальных/публичных источников.
- Офлайн-профиль предназначен для локального тестирования/одиночной игры и не обходит авторизацию серверов.
- Мод должен соответствовать загрузчику (Fabric/Forge/NeoForge) и версии игры. Эта первая версия ищет и скачивает файл с Modrinth, но не устанавливает загрузчик автоматически; файл сохраняется в папку `mods` выбранного профиля.
